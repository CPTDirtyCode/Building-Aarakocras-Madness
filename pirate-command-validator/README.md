# Pirate Command Validator

A beginner-friendly Python project that validates user input, cleans answers, and keeps asking until a valid command is entered.

## Features

- Cleans input with `lower()` and `strip()`
- Validates commands
- Rejects invalid responses
- Uses reusable functions
- Demonstrates while loops and sets

## Concepts Learned

- Functions
- While loops
- String Cleaning
- Input Validation
- Sets
- Membership Operators

## Example Run

```
Ahoy! The crew awaits your command.

Do you want to raise the sails? (yes/no)
> banana
The quartermaster squints at you.
That answer belongs at the bottom of the sea.
>
The quartermaster stares at you in silence.
Even the parrot says more than that. Try again!
>   YES
Accepted, matey!
Full speed ahead!

Choose a direction. (left/right)
> up
The quartermaster squints at you.
That answer belongs at the bottom of the sea.
> Left
Accepted, matey!
The ship turns left!
```
